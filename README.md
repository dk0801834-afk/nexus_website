# NexusFlow - SaaS Website

I have created a SaaS-based website inspired by NexusFlow, designed to showcase intelligent solutions for modern businesses. 

## 🚀 Features
* **Modern UI/UX:** Responsive design featuring use cases for E-commerce, Healthcare, Financial Services, and more.
* **Dynamic Templates:** Frontend built with HTML/CSS and rendered via Flask templates.
* **Contact Management:** Fully functional contact form linked to a backend SQLite database (`contact_database.db`).
* **SaaS Features Showcase:** Highlights workflow automation, enterprise security, and advanced analytics.

## 🛠️ Tech Stack
* **Backend:** Python, Flask (`app.py`)
* **Frontend:** HTML, CSS, JavaScript (`templates/` and `static/` directories)
* **Database:** SQLite (`contact_database.db`)
